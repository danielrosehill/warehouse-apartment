# inbox-eubox-highlights/

Unfiled drop of the "Eurobox highlights" selection — best-of shots pulled from the
phone roll, to be sorted into the theme folders above (`sourcing/`,
`storage-system/`, `picking-bins/`, `moving-equipment/`, `moving-day/`, `extras/`)
and renamed descriptively when there's time.

Still camera filenames (`IMG<date><time>.jpg`), still JPEG rather than the WebP the
filed set uses.

**Redaction status:** inventory QR codes were covered **by hand** before these were
copied in — they did *not* go through [`tools/redact_qr.py`](../../tools/redact_qr.py).
EXIF (including GPS) was stripped separately with `exiftool -all=`.

One photo from the selection is deliberately **not** here: it shows a child's face
unblurred, so it is held in the git-ignored `photos/raw/` until it is blurred or
dropped.
